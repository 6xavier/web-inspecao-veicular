## Próxima Sprint
Estamos focando em definir os requisitos parta o sistema, alguns exemplos são:

- O sistema deve permitir o cadastro de clientes.
- O sistema deve permitir associar um veículo a um cliente.
- O sistema deve permitir consultar horários disponíveis.
- O sistema deve permitir selecionar o tipo de inspeção.
- O sistema deve permitir realizar um agendamento.
