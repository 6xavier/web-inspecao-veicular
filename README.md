# Sistema de Gestão e Agendamento para Inspeção Veicular
### Projeto desenvolvido para a UC de **Projeto e Engenharia de Software** e com o objetivo de criar uma solução para auxiliar no agendamento e gerenciamento de serviços de uma empresa de inspeção veicular.

## **Sobre o Projeto**

O projeto propõe o desenvolvimento de um sistema de gestão e agendamento voltado para empresas de inspeção veicular.
A plataforma permitirá que clientes realizem agendamentos para diferentes tipos de inspeção, como **GNV, Modificação, Sinistro, CIV, CIPP etc**. O gestor poderá visualizar agendamentos, dúvidas, relatórios e faturamento.

## **Nicho**

Empresas prestadoras de serviços de **inspeção veicular**, atendendo proprietários de veículos sinistrados/ou modificados, veículos com GNV, caminhões e outros veículos que necessitem dos serviços disponibilizados pela empresa.

## **Objetivo**

Facilitar o processo de agendamento de inspeções veiculares e proporcionar uma forma mais organizada de gerenciamento dos atendimentos.
